[NAME:DFCN - Chinese Localization]
[DESCRIPTION:Windows x64 localization for Dwarf Fortress 53.16, supporting Steam and Classic editions. Shift+F8 switches Simplified Chinese and Taiwan Traditional Chinese using bundled offline OpenCC. The choice lasts for the current session, including core reloads. Set language=zh-Hans or language=zh-Hant in the game directory's dfcn_config.ini for the default language; this file is created from the bundled config.ini if absent. Copy DFCN/dfhooks.dll and DFCN/dfhooks_dfcn.ini to the game directory. Set the INI first line to the actual Workshop path of DFCN/dfcn/dfhooks_dfcn.dll; keep the complete DFCN folder in the subscription directory. Automatically discovers separate translation data extensions. No DFHack dependency. See INSTALL.txt.]
