# Mcnuggy's Mythical Beasts 简体中文汉化

适配原模组 **3.2（NUMERIC_VERSION 302）**，作为独立的 DFCN 汉化数据扩展使用。

需要 [Mcnuggy's Mythical Beasts 原模组](https://steamcommunity.com/sharedfiles/filedetails/?id=3010868752)和 [DFCN 汉化核心](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)。

翻译范围包括生物与巨型变种、雌雄与幼体名称、树人成长阶段、生物介绍与偏好、半人马专属职业、身体部位与组织、特殊材料及其物态、乳制品、曼德拉草及其叶片、种子和酒，以及能力名称、石化与中毒等状态、战斗动作和声音。

ZIP 中的 `dfcn_mcnuggys_mythical_beasts_zh_hans` 文件夹放入游戏 `mods` 目录后，由 DFCN 在读取扩展数据时自动发现，无需在创建世界时启用本汉化包。原模组仍按其正常方式使用；本包只提供显示译文，不包含原模组 RAW、图像或玩法修改。

中文名称采用同一套词汇，例如 griffon 为“狮鹫”、hippogriff 为“鹰头马身兽”、cockatrice 为“鸡蛇”、basilisk 为“蛇怪”、phoenix 为“不死鸟”、qilin 为“麒麟”。保留原文中的拼写作为匹配键，包括 `metalic feathers`、`fith eye` 等，避免原模组的拼写差异使译文失配。用户自定义名称不由本包改写。

原模组作者：mcnuggy。本包为 DFCN 社区制作的非官方简体中文翻译扩展，与原模组分开分发。
