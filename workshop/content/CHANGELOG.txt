DFCN v53.16-20261020

2026-10-20 · Windows x64 · Dwarf Fortress 53.16（Steam 版与官网免费版）

本次从 Linux 使用仓库的 build-windows-cross.sh 交叉编译 Windows 核心与加载器。更新范围为上次 Release v53.16-20261019.3 至 31da1c8cb00e7030156fc844747071383b5e504d，共 16 条提交；下文按提交顺序逐条说明。

更新内容

- 修复抵达新要塞时的栈溢出问题：大型图形快照改为按需在堆上分配，抵达说明优先使用专用翻译逻辑，避免被公告解析器误当成人名或作品描述。
- 优化通知与冒险公告的翻译响应和滚动处理：保留已完成的译文与预热结果，优先处理当前可见记录，减少重复文本捕获、名称解析和整段重绘。
- 修正战斗报告中人物、物品与动作的归属，避免将未解析的战斗字段误当作普通人名或物品；调整飞射物袭击、跳跃闪避与抓附动作的措辞。
- 修复区域详情中会馆名称、职业和等级说明的漏译，使用原始完整文本处理游戏省略号截断；修复经典界面 Pets/Livestock、Dead/Missing 等含斜杠标签。
- 补全带昵称、职位或领地的职业变更公告；将相关对话译文调整为“生命如此短暂……”。
- 新增基于真实河流对象的中文意象命名：世界生成、选址和旅行界面共享河流名称来源，结合完整词槽、全程规模和地形选择名称与通名；不适用意象规则时保留完整名称的音译回退。
- 适配 Windows DFHack 53.16-r3 的绘制、Lua 输出及关闭流程，保留 r2 支持；修复通知横幅识别、滚动条占位和无人接手任务缺少名称时的提示。
- 随包提供思源黑体简体粗体及字体许可；默认配置的最小字号改为 16，字体比例仍为 1.1。已有游戏根目录 dfcn_config.ini 不会被覆盖。

下载与安装

- DFCN-Windows-x64-minimal.zip：完整 Windows 运行包。将 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹按目录结构解压到游戏根目录。
- DFCN-Windows-workshop.zip：与创意工坊上传目录一致的 Windows 工坊包，入口 INI 指向订阅目录；安装方法见包内 INSTALL.txt。
- Dwarvemon、Dwarvemon Beta、Dwarvemon Entity All、Dwarvemon Entity Type 四个独立汉化数据 ZIP 继续分别提供。本次没有宣称它们新增翻译内容，也不将其合并进本体。

本次未生成新的 Linux 运行包。下列 Linux 地图修复属于源码提交记录，不代表旧 Linux Release 已更新。编译与打包不代表已观察到游戏内最终显示或性能效果。
