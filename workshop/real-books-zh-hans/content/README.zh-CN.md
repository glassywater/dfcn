# 真实书籍与卷轴内容：本地汉化数据包

对应当前订阅的 `Real Book/Scroll Content!` 1.57（创意工坊项目 `3752219300`），本地版本 `1.0-local`，未发布。

译文保存在 `dfcn/translations.tsv` 与 `dfcn/rulesets/zh-Hans/subscribed_books`。数据覆盖 Mod 简介、DFHack 界面控件、书籍结构标签、原作者的正文模板、文体模块、扩写、世界和角色描写、事件解释、叙述框架、对白、性格、战斗、诗歌、音乐、舞蹈及其动态词池。宝可梦及其他订阅 Mod 的翻译分别保存在各自的数据包。

DFCN 通过本包的 `dfcn-extension.toml` 自动载入数据。完整正文只使用原 Mod 的 `codex-narrator` 窗口 `content` 控件声明，不将书籍叙述句式用于全局名称或小队别名。实际人物、地点和物品名称在有对应译文时使用译文，其余身份原样保留。

作者最终生成正文时会修正冠词和代词大小写，低技能作者还会插入衔接词或重复单词。本包包含这些生成变化的兼容数据；长文按完整段落、诗节及句式处理。原订阅的 RAW、Lua 和书籍生成过程保持原样。

本包依赖支持独立数据扩展与显式正文声明的 DFCN 核心及原 Mod。包的本地安装由项目正常编译部署入口完成，独立 ZIP 将整个 `dfcn_real_books_zh_hans` 文件夹放入游戏 `mods`；无需在创建世界时启用汉化数据包。

本次没有操作游戏或观察实机最终显示，交付为本地待测试版本。
