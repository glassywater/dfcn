[NAME:DFCN - Chinese Localization]
[DESCRIPTION:Windows x64 localization for Dwarf Fortress 53.16, supporting Steam and Classic editions. Shift+F1 opens or closes the translation settings menu: toggle Chinese/English, Simplified/Traditional Chinese, original spelling/Chinese transliteration for the four races' languages, installed DFHack, or reload the translation core and data. Chinese transliteration is enabled by default; the selection lasts for the current session, including core reloads. The menu also works in English mode; Esc or right-click closes it. Shift+F8 switches Simplified Chinese and Taiwan Traditional Chinese using bundled offline OpenCC. The choice lasts for the current session, including core reloads. Set language=zh-Hans or language=zh-Hant in the game directory's dfcn_config.ini for the default language; this file is created from the bundled config.ini if absent. Copy DFCN/dfhooks.dll and DFCN/dfhooks_dfcn.ini to the game directory. Set the INI first line to the actual Workshop path of DFCN/dfcn/dfhooks_dfcn.dll; keep the complete DFCN folder in the subscription directory. Automatically discovers separate translation data extensions and the optional semantic-search model mod. Semantic search is active only when that independent model mod is installed. No DFHack dependency. See INSTALL.txt.]
