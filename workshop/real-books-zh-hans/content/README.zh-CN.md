# Real Book/Scroll Content! 简体中文汉化

翻译阅读界面、书名、文体和生成的书籍正文。

附带由本汉化包维护的 DFHack 兼容脚本：每次生成书籍时只建立一次写作事件索引，并复用已取得的查询模块，避免手册对世界中每本作品重复遍历完整历史、搜索脚本路径和读取文件时间。保留完整正文和原有年份筛选；不修改原模组文件。

需要 [DFCN 汉化核心](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)和[Real Book/Scroll Content!](https://steamcommunity.com/sharedfiles/filedetails/?id=3752219300)。原模组需 DFHack。
订阅后由 DFCN 自动读取，无需在创建世界时启用本汉化包。
兼容脚本由 DFHack 的已安装模组脚本机制自动加载，也无需加入世界模组列表。
本地安装须将整个汉化包（包括 `scripts_modinstalled`）放入游戏实际使用的用户数据目录下的 `mods`；Windows 游戏通过 Proton 运行时，该目录位于其前缀的 `AppData/Roaming/Bay 12 Games/Dwarf Fortress`。
