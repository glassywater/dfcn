# DFCN v53.16-20261004 · 2026-10-04

Windows x64 精简运行包，适配 **Dwarf Fortress 53.16**，支持 Steam 版与官网免费版。

本次新增游戏本体搜索框的拼音及拼音首字母搜索、可选像素字体整数倍缩放，统一字号与行距，修复交易、人物概述、神祇与神殿、工坊、冒险菜单、模组和设置页的翻译与排版；同时合入 Linux 官网版初始化、独立源码构建部署及渲染性能优化。

更新范围：上次 Release v53.16-20261003.2（8b862e5）之后，截至 e441939 的全部 48 条提交，包含 46 条开发提交和 2 条合并提交，按 git log --reverse 顺序逐条列出；合并记录不另算为新的功能。

## 使用变化

- 游戏本体的中文译名可用全拼、分隔拼音及首字母搜索，例如“铁矿”可输入 tiekuang、tie kuang 或 tk；继续支持中文与英文。新增的 Windows 专用搜索入口和共享部分在逐条日志中分别说明，DFHack 搜索未改动。
- 运行包默认 font_scale=1.1、min_font_pixels=12、font_bold=true、font_pixels=0。沿用个人 config.ini 时继续以自己的设置为准。
- 新增 font_pixel_grid，默认 0，保留普通字体渲染。使用点阵字体时可设为 12，以 12、24、36px 等整数倍放大单色字形，配合 font_pixels=0、font_scale=1.1、min_font_pixels=12、font_bold=true。正数 font_pixels 也向下取基准网格整数倍，至少一倍；最终输出仍存在非整数倍缩放时，像素宽度可能不均。
- 输入框与第三方模组名称、作者和说明保留原文；游戏自带模组说明和固定界面标签继续汉化。
- 本 Release 附件及本次工坊上传提供 Windows x64 运行文件；Linux 专用提交已纳入源码，新增原生构建、双版本部署与 Linux 运行包打包入口。感谢 LYHGLYTX 的 Linux 适配与性能优化贡献（PR #1、#3）。

## 下载与安装

下载附件 DFCN-Windows-x64-minimal.zip，将 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹按压缩包目录结构解压到包含 Dwarf Fortress.exe 的游戏根目录。Release 包内入口路径为 dfcn/dfhooks_dfcn.dll，汉化设置位于 dfcn/data/runtime/config.ini。

[Steam 创意工坊订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)提供解压后的相同 Windows 运行内容。工坊版的两个入口文件指向订阅目录，安装方法见工坊说明；完整逐条日志随订阅内容提供在 CHANGELOG.txt。运行包包含加载器、汉化核心、配置、词表、规则及第三方许可，不包含游戏程序、源码或开发工具。

本次使用当前 Windows DLL 和运行数据打包，未操作游戏或实际观察游戏内最终显示效果。
