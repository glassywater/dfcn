# 装饰坊汉化数据

对应本机订阅的 Decoration Emporium（工坊 ID 3802396587，数字版本 3）。翻译两座工坊名称、火炬、酒馆招牌、工业旗帜、兽皮与布地毯、镜子、杂物摆饰、矛上首级的全部编号与变体、配方、模组完整说明和更新说明。原文件里的 hoap 为 Head On A Pike 的缩写，显示为“矛上首级”。数字及 a、b、c、d 变体保留，便于识别同组物品。

工具名称与制作配方分别接入物品和菜单语法，供原版材料、质量、磨损、数量与供奉处共享。完整说明保留原换行，同时提供空白折叠形式。本包不修改原模组或世界规则，无需在创建世界时启用。需要支持数据扩展的 DFCN。尚未发布，尚未观察游戏内效果。
