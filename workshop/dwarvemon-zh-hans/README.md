# 矮人宝可梦汉化数据

为 **Dwarvemon 2.22** 和 **Dwarvemon Entity All 2.22** 提供简体中文翻译，覆盖宝可梦及形态名称、描述、偏好、道具、材料、植物、工坊与配方、身体部位、招式、特性、进化提示、战斗公告和历史事件。

需要安装 [DFCN 汉化核心](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)。本体的 [GitHub Release](https://github.com/pokemonchw/dfcn/releases/tag/v53.16-20261008)提供 `DFCN-Windows-x64-minimal.zip`。

订阅 [矮人宝可梦汉化数据](https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177)后，核心会自动识别，无需手工复制数据。使用 GitHub 下载方式时，从同一 Release 下载 `dfcn_dwarvemon_zh_hans.zip`，将其中整个 `dfcn_dwarvemon_zh_hans` 文件夹解压至游戏 `mods` 目录。

本数据包无需在创建世界的模组列表中启用。原始 Dwarvemon 模组仍按其作者说明使用。核心会自动识别数据包的更新或移除；没有完整译文的名称和内容保留原文，用户自定义小队名称保持原样。

本包只提供翻译数据，不修改两个原模组的 RAW 或世界规则，不包含 DLL。中文专名优先采用宝可梦官方简体中文译名；原模组自创内容和没有官方译名的内容另行翻译，少量旧树果名称参考中文百科暂译。

`content/` 是创意工坊上传内容；`sources/` 保存本次翻译的来源资料，不参与运行时加载。来源与许可说明见 `content/DATA-LICENSE.txt`。运行时入口为 `content/dfcn-extension.toml`。
