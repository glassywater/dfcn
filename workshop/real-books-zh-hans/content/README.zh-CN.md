# 真实书籍与卷轴内容：本地汉化数据包

对应当前订阅的 `Real Book/Scroll Content!` 1.57（创意工坊项目 `3752219300`），本地版本 `1.4-local`，未发布。

译文保存在 `dfcn/translations.tsv` 与 `dfcn/rulesets/zh-Hans/subscribed_books`。数据覆盖 Mod 简介、DFHack 界面控件、书籍结构标签、原作者的正文模板、文体模块、扩写、世界和角色描写、事件解释、叙述框架、对白、性格、战斗、诗歌、音乐、舞蹈及其动态词池。宝可梦及其他订阅 Mod 的翻译分别保存在各自的数据包。

DFCN 通过本包的 `dfcn-extension.toml` 自动载入数据。完整正文只使用原 Mod 的 `codex-narrator` 窗口 `content` 控件声明，不将书籍叙述句式用于全局名称或小队别名。实际人物、地点和物品名称在有对应译文时使用译文，其余身份原样保留。正文书名沿用本体书名翻译；视角词池包含参考书文体，并使用有限词池匹配，避免把后续章节捕获成视角名称。章节、诗节和幕数只匹配数字，避免把后续正文捕获成编号。跨行诗歌保留完整句式；跨段落作品同时提供对应段落的译文。

参考书和叙述框架中自行添加“年”的句式使用纯数字年份词池，避免重复年份单位。阅读窗口通过明确的 `{book}` 字段使用与正文、物品详情相同的书名翻译规则，无法解析的书名保持源名。

正文入口每次消费最长的完整作品片段，保留多句与诗行规则、句间空白和段落分隔。段落之间由核心迭代拼接，不递归枚举整本书的句段匹配组合；未知句子原样显示。最近一篇正文的翻译按控件身份、原文和资源版本复用，切换书籍时替换。

作者最终生成正文时会修正冠词和代词大小写，低技能作者还会插入衔接词或重复单词。本包包含这些生成变化的兼容数据；长文按完整段落、诗节及句式处理，书籍生成过程保持原样。

本机订阅 Mod 的阅读按钮另有一处选书修复：物品详情使用 `view_sheets.active_id`，只有单项物品列表才使用列表首项，避免叠放时读取其他书。本地原 Lua 已修改；源码包的 `../patches/codex-narrator-selected-book.patch` 保存对应改动，不由数据扩展自动应用。

本包依赖支持独立数据扩展与显式正文声明的 DFCN 核心及原 Mod。包的本地安装由项目正常编译部署入口完成，独立 ZIP 将整个 `dfcn_real_books_zh_hans` 文件夹放入游戏 `mods`；无需在创建世界时启用汉化数据包。
