# 缤纷釉彩汉化数据

对应本机订阅的 Better Glazing（工坊 ID 3792463423，数字版本 12）。翻译 41 种釉料、41 种颜色与瓦陶、炻瓷、瓷器组成的 123 种陶瓷材料、制釉与混釉作业、123 项陶砖配方、四项普通上釉配方、五个配方分类及完整说明、模组名称与完整游戏和工坊简介。

釉料和陶瓷规则接入材料名与形容词语法，供粉末、砖块、构筑物、墙壁、地面和材料选择共享；配方接入菜单语法。矿物与三种陶瓷类别沿用 DFCN 现有译名，颜色在本包中按颜色含义翻译。

本包不修改原模组或世界规则，无需在创建世界时启用。需要支持数据扩展的 DFCN。尚未发布，尚未观察游戏内效果。
