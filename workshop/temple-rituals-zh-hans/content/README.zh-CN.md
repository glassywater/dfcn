# 神庙祭仪汉化数据

原模组：Temple Rituals（程序生成），作者 fishy，工坊编号3642982349。来源是本机订阅的1.1（数字版本11），目录 D:\program\steam\steamapps\workshop\content\975370\3642982349。

覆盖 objects RAW 的祭坛名称、提示、灵气/治疗之雾/腐烂和淤浆材料，以及 scripts/init.lua、sphere_data.lua、generics_data.lua、temple_necromancers.lua 产生的玩家可见文本。包括所有33个饮剂形容词、27个饮剂名词、24个饮剂祝福效果、18个祭司称号及其原作者生成复数、10种主要供品、祭仪名称/分类、全部冒险模式技能与施法动词。程序生成饮剂和祭司名称按完整规则翻译，神祇身份保留原世界名称；只在完整且其余字段已翻译的句型中使用带回溯边界的神名槽。死灵称号还覆盖原模组调用的原版 secret.lua 名称词池及复数。

本包全部资源独立，不更改原模组 RAW、生成脚本或 DFCN 本体词表。不会在生成器中改写名称。生物、武器及装饰物引用原版 RAW 标识，使用 DFCN 既有的物品、生物、神造金属翻译。世界中的神祇/人物身份及用户自定义小队名保持身份本身；原作者提供的祭司称号、材料词池和供品均译为中文。

未发布，不带工坊身份。将整个目录放入游戏 mods/dfcn_temple_rituals_zh_hans 后，DFCN 自动读取，无需在世界模组列表中启用汉化数据包。原 Temple Rituals 模组仍需保留。

数据制作已完成；尚未操作游戏，也尚未观察到实机最终显示效果。原模组的潜在行为问题仍由原模组决定，其 debug_level 与 tests.lua 不由本包运行或更改。
