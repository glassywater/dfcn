DFHack logistics.autoretrain：安装版 Lua 绘制链与可见文本提取

材料性质
本文件来自安装版可读 Lua 原文，不是 Lua 字节码反编译，也不替代原生
logistics.plug.dll / dfhack.dll 的反编译。原生状态函数的结果进入下述
Lua 绘制链；原生反编译材料由同目录的配套材料另行记录。
这是来源提取材料，不是测试、检查报告或游戏内效果记录。

D:/program/steam/steamapps/common/DFHack/hack/lua/

   以 env_name .. '.' .. widget_name 拼出实例名，因此实例为

   require('plugins.' .. plugin)，将插件名和模块环境交给 load_widgets；

   CREATURES/PET、Pets/Livestock 及默认 y=-4 的来源追溯，只有上述

   sort/info.lua:438、526 绑定的是 CREATURES/AssignWorkAnimal，

   不构成此框的另一种标签。全局 dwarfmode overlays 可以同屏，
   用户位置配置也可能移动其他组件；它们不是此组件的文本分支。

文本生成链

   Panel: frame={t=0,h=3}，frame_style=gui.FRAME_MEDIUM，
   frame_background=gui.CLEAR_PEN。

   view_id='toggle'；key='CUSTOM_CTRL_A'；label='Autoretrain livestock:'；
   on_change 调用 logistics_setFeature(val,'autoretrain')。
   没有传入 options、key_back、label_width 或 label_below。
3. gui/widgets/labels/toggle_hotkey_label.lua:9-13：继承 CycleHotkeyLabel；
   options={{label='On',value=true,pen=COLOR_GREEN},
            {label='Off',value=false}}。
   本框所有状态标签只有 On、Off。未设置第三选项，也没有按宠物种类、
   训练程度、世界状态或其他物流功能改写 label 的分支。
4. gui/widgets/labels/cycle_hotkey_label.lua:35-45：key_sep=': '、option_gap=1、
   label_below=false、initial_option=1。
   48-61 行创建文本 token：按键 token 与固定标签，然后一格 gap，
   然后 getOptionLabel() 返回的动态状态标签。
5. gui/widgets/labels/label.lua:136-138、179-199：对文本 token 求值；
   gui.getKeyDisplay(token.key) 产生动态按键显示，接 token.key_sep，
   接固定标签。gui.lua:219-223 将字符串键名映射为 df.interface_key，
   然后调用原生 dscreen.getKeyDisplay。
   截图中显示 Ctrl+a，但源码通过 CUSTOM_CTRL_A 动态读取键名显示；
   Ctrl+a 不是本组件另一个待译词条，不能把截图按键绑定写死成标签。

完整语义分支
开启：plugins/logistics.lua:315-317 每帧调用
      self.subviews.toggle:setOption(logistics_getFeature('autoretrain'))。
      返回 true 时选 On，pen=COLOR_GREEN。
      标准按键显示下形成 Ctrl+a: Autoretrain livestock: On。
关闭：同一调用返回 false 时选 Off，使用默认文本 pen。
      标准按键显示下形成 Ctrl+a: Autoretrain livestock: Off。
选项解析：gui/widgets/labels/cycle_hotkey_label.lua:86-107 根据选项 value
          查找对应 index；未匹配才按 index 查找，仍未匹配回到第1项。
          所有路径仍只能选 On/Off，不产生其他英文文本。
状态文字读取：同文件 110-120 返回所选 option.label，123-124 返回 value。
前向切换：同文件 71-83 在两项间循环，末项回到首项，调用 on_change。
鼠标点击：同文件 133-141，先交给父类按键处理；左键命中且可用时 cycle。
          此组件没有 key_back，所以没有后向快捷键及额外按键文字。
