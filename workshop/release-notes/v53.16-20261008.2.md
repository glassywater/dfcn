# DFCN v53.16-20261008.2 · 2026-10-08 第二版

适用于 Dwarf Fortress 53.16。Windows x64 运行包使用当前已有的构建产物及运行数据，代码范围从上一 Windows release `v53.16-20261008`（`a9df84f`）更新至 `5a212a2`。

[查看上一 Windows release 至本次代码的完整差异](https://github.com/pokemonchw/dfcn/compare/v53.16-20261008...5a212a2da09329464878801894c21b41ea986538)。

## 界面与翻译修复

- 修复动物训练中的完整生物名称、带标点名称和无性别生物列表排版；将绵羊、幼崽、奶与奶酪译名统一为“绵羊”“绵羊幼崽”“绵羊奶”“绵羊奶酪”。
- 修复模组管理器的完整名称、标题、控件、预设提示及相关弹窗汉化；修复中文模组元数据乱码与 UTF-8 换行，保留模组原名。
- 修复 DFHack 顶部命令栏覆盖模组页时的排版错位，以及 DFHack 输入被底层原生文本框抢先消耗；补齐 `showmood` 完整报告与材料清单翻译。
- 修复库存分类被误当名称音译、带标签的模组植物与地形名称、模组工坊和配方分类悬浮说明、启程准备失败提示、皮甲制作的皮革和尺寸字段。
- 补齐祷告、冥想和布道活动的对象翻译，保留神名的冠词与称号组合；补齐隐遁者姓氏双字组合，修复要塞等级、爵位和职位标签。
- 修复传说人物目录日期后缀影响整行翻译、目录行被误识别为详情标题，以及编年史击杀事件中的扩展犬种。未知种族只保留对应字段原文，事件其余部分继续翻译；最新 Windows 代码进一步修正 Whaleys Dogs 犬种命名空间。
- 用户自定义小队名称继续原样显示，包括英文、数字组合和中文。

## 独立模组汉化数据与书籍

源码与本地数据新增并完善 19 个独立汉化数据包，覆盖 23 个订阅项目：Dwarvemon 系列共用一包，另外提供 clinodev's dry mines、Squad & Burrow Icons、Whaleys Dogs、Dwarven Tea Party、SoundSense Originals、Fumo item、Dwarven Core Harvesting、Topples' Workshop Icons、Topples' Smoking、Detailed Moon、Brewing Plus、Altar of Blessings、Temple Rituals、Item Tagger、Real Book/Scroll Content!、Stone Tint、Better Glazing 和 Decoration Emporium 的独立数据。

宝可梦共享包增加 Beta 随包的 PMD、TCG、MissingNo、WerePokemon 和作弊工坊译文。独立数据包提供模组简介、界面、专用词池与动态正文；本体扩展加载现支持 DFHack 界面、输出、帮助和显式声明的正文。汉化数据包无需加入创建世界的 RAW 加载顺序，原模组仍按作者说明使用。

上述独立数据变化属于源码及本地数据包，本次主运行包不内置这些模组专用数据；本次 GitHub release 不上传这 19 个独立扩展 ZIP，也不更新宝可梦数据工坊。实际使用对应新译文仍需相应独立数据包。

Real Book/Scroll Content! 的正文数据覆盖文体模块、扩写、世界与角色描写、事件解释、叙述框架、对白、性格、战斗、诗歌、音乐与舞蹈。修复原生书单标题及阅读窗口书名，补齐参考书视角和句式，修复重复年份单位、章节编号与视角词池过度捕获。正文按完整作品片段迭代解析，并按控件、原文和资源版本缓存，避免递归枚举整本书导致卡死；跨行诗歌保留句式和段落分隔，未知句子保留原文。

书籍句式只作用于声明的正文控件，修复其干扰普通生物名称翻译的问题。源码另保存叠放书籍选取的原模组 Lua 补丁；该补丁不会由翻译数据包自动应用，运行包不宣称自动修复原模组的选书逻辑。

## 快捷键与性能

- `Shift+F10`：开启或关闭汉化显示，保留当前核心与数据。
- `Shift+F5`：关闭汉化；再次开启时重新加载核心与数据。
- `Ctrl+Shift+F10`：显式刷新配置与词表。数据在启动或显式加载时读取，已移除文件变化的自动刷新。
- 优化各类中文、拼音及首字母搜索：缓存查询、译文、拼音索引与多音字状态，复用连续追加查询的排除结果，减少大目录重复计算和缓存反复淘汰，各搜索入口保留自身语义上下文。
- 优化规则引用图和 DFHack 词条载入；最新 Windows 代码修正字体配置初始化顺序、使用有界缓冲读取发音模型，并只分析根可达规则，减少初始化的重复工作与临时内存。

## 安装

### Windows：GitHub ZIP

下载 `DFCN-Windows-x64-minimal.zip`，将压缩包内所有内容按原目录结构复制到含 `Dwarf Fortress.exe` 的游戏根目录，包括 `dfhooks.dll`、`dfhooks_dfcn.ini` 和完整 `dfcn` 文件夹。配置位于游戏目录的 `dfcn/data/runtime/config.ini`。

### Windows：Steam 创意工坊

订阅 [DFCN 汉化](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)，运行文件位于 `steamapps/workshop/content/975370/3811193379/DFCN/`。将其中的 `dfhooks.dll` 和 `dfhooks_dfcn.ini` 复制到含 `Dwarf Fortress.exe` 的游戏根目录，其余文件保留在订阅目录。游戏与工坊内容位于同一 Steam 库时，INI 第一行填写：

```text
../../workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll
```

分属不同 Steam 库时，该行填写 DLL 的实际绝对路径；只写路径，不加引号或 `key=value`，保存为 UTF-8 无 BOM。配置位于工坊 `DFCN/dfcn/data/runtime/config.ini`。

### Linux：Steam 创意工坊或 GitHub 原发布包

工坊内从 `steamapps/workshop/content/975370/3811193379/DFCN-Linux/` 将 **`libdfhooks.so` 和完整 `dfcn` 文件夹一起复制**到含 **`dwarfort`** 的游戏根目录，保留目录结构。直接下载 Linux release 的 `DFCN-Linux-x64-minimal.zip` 时，也将其中的 `libdfhooks.so` 与完整 `dfcn` 一起解压至游戏根目录。Linux 配置位于游戏根目录的 `dfcn/data/runtime/config.ini`。

Linux 原生包依赖系统的 SDL2、FreeType、Fontconfig、C++ 运行库及 glibc，包内不附带这些系统依赖；未内置字体时，Fontconfig 使用系统已安装的中文无衬线字体。普通汉化无需 DFHack；相关 DFHack 原生功能以 53.16-r2 为参考。

### 独立汉化数据包

已发布的 [矮人宝可梦汉化数据](https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177) 使用独立工坊订阅身份，旧版 ZIP 仍见 [上一 release `v53.16-20261008`](https://github.com/pokemonchw/dfcn/releases/tag/v53.16-20261008)；本次未更新该独立工坊及其 ZIP。安装已有独立 ZIP 时，将其中整个 `dfcn_*_zh_hans` 目录解压至游戏 `mods`。数据包在核心启动或显式重新加载数据时发现，无需在创建世界的模组列表中启用汉化数据包。其余新增独立数据包本次仅保留在源码与本地数据中。
