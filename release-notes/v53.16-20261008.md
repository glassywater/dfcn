# DFCN v53.16-20261008

发布日期：2026-10-08。适用游戏版本：Dwarf Fortress 53.16。

本版增加通用汉化数据扩展自动加载，将 Dwarvemon 2.22 与 Dwarvemon Entity All 2.22 的全部专用译文拆为独立数据包。核心自动识别数据包的安装、更新和移除，词条与规则按对应语义范围载入。没有完整译文的 mod 名称、简介和工坊名称保留原文，用户自定义小队名称保持原样。

宝可梦数据包覆盖名称与形态、描述、偏好、道具、植物、材料、身体部位、工坊与配方、招式、特性、进化提示、战斗公告和历史事件。专名优先采用官方简体中文译名；原创内容完整翻译，部分旧树果采用百科暂译。全部宝可梦专用翻译位于独立包，本体仅提供通用翻译及扩展加载能力。

## 下载与安装

| 资产 | 用途与安装方式 |
| --- | --- |
| `DFCN-Windows-x64-minimal.zip` | Windows x64 核心运行包。将全部内容按原有结构解压至包含 `Dwarf Fortress.exe` 的游戏根目录，包括加载入口及整个 `dfcn` 文件夹。 |
| `dfcn_dwarvemon_zh_hans.zip` | 独立宝可梦汉化数据。将压缩包中的整个 `dfcn_dwarvemon_zh_hans` 文件夹解压至游戏 `mods` 目录。 |

本次提供适用于 Dwarf Fortress 53.16 的 Windows x64 核心运行包。

使用创意工坊时，订阅 [DFCN 本体](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)，按本体安装说明配置加载入口；再订阅 [矮人宝可梦汉化数据](https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177)，数据包会自动识别，无需手工复制其中的数据。

汉化数据包无需在创建世界的模组列表中启用，不修改原始模组 RAW 或世界规则。原始 Dwarvemon 模组仍按其作者说明使用。安装方式和扩展格式见 [README](https://github.com/pokemonchw/dfcn/blob/v53.16-20261008/README.md) 与 [汉化数据扩展说明](https://github.com/pokemonchw/dfcn/blob/v53.16-20261008/docs/translation-extensions.zh-CN.md)。
