# Dwarvemon Beta 简体中文汉化

Dwarvemon Beta 的简体中文汉化数据。翻译宝可梦、道具、工坊及随包的 PMD、TCG、MissingNo 和其他可选模块。

需要 [DFCN 汉化核心](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379) 与 [Dwarvemon Beta](https://steamcommunity.com/sharedfiles/filedetails/?id=2902397057)。订阅后由核心自动读取，无需在创建世界的模组列表中启用汉化数据包。
