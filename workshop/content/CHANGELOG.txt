DFCN v53.16-20261008.2 · 2026-10-08 第二版

本次 Windows 更新范围：上一 Windows release v53.16-20261008（a9df84f）至 5a212a2。
同一工坊新增 DFCN-Linux/，使用 GitHub 已发布的 v53.16-20261008-linux（71c34d7）原运行包；Linux 未在本次重新构建，不包含其后 5a212a2 的最新修复。

- 修复动物训练中的完整生物名称、带标点名称及无性别生物列表排版；统一绵羊、绵羊幼崽、奶与奶酪译名。
- 修复模组管理器的名称截断、界面排版与预设提示漏译，修复中文模组元数据乱码并保留模组原名；修复顶部命令栏覆盖模组页时的汉化错位及 DFHack 输入被原生文本框抢先消耗。
- 源码与本地数据新增并完善 19 个独立模组汉化数据包，覆盖 23 个订阅项目；扩展 DFHack 界面、输出、帮助、动态正文与具名词池加载。宝可梦共享数据包补齐 Beta 的 PMD、TCG、MissingNo、WerePokemon 与作弊工坊内容。本次主运行包不内置这些独立数据，不发布这 19 个扩展 ZIP，也不更新宝可梦数据工坊。
- 完善 Real Book/Scroll Content! 的界面、文体、世界与角色描写、对白、战斗、诗歌、音乐、舞蹈和生成正文；修复原生书单标题与阅读窗口书名。长文按完整作品片段迭代解析并缓存，避免整本书递归组合导致卡死；修复年份重复、章节编号和视角词池过度捕获。另保存叠放书籍选取的原模组 Lua 补丁，数据包不会自动应用该补丁。
- 将书籍正文规则限制在明确声明的正文控件，修复其阻断生物翻译的问题；用户自定义小队名称继续原样显示。
- 修复库存分类被误当名称音译、带标签的模组植物与地形名称、模组工坊及配方分类悬浮说明、启程准备失败提示，以及皮甲制作的材料与尺寸字段。
- 补齐祷告、冥想、布道活动的对象翻译，保留神名冠词与称号组合；补齐隐遁者姓氏双字组合，修复要塞等级、爵位与职位标签。
- 修复传说人物目录日期后缀影响整行翻译、目录行被误识别为详情标题，以及编年史击杀事件中的扩展犬种；未知种族保留该字段原文并继续翻译事件。Windows 最新版另修正 Whaleys Dogs 的犬种命名空间。
- 修复 DFHack showmood 完整报告与材料清单汉化。
- Shift+F10 仅切换汉化显示并保留当前核心与数据；Shift+F5 关闭再开启时重载核心与数据；Ctrl+Shift+F10 显式刷新配置与词表。移除文件变化自动刷新。
- 优化各类中文、拼音与首字母搜索，缓存查询、译文、拼音索引、多音字状态及连续追加查询的排除结果，减少大目录重复计算与缓存淘汰。
- 优化规则引用图、发音模型和 DFHack 词条载入；Windows 最新版修正字体配置初始化顺序，以有界缓冲读取发音数据，并仅分析根可达规则。
- Linux 原发布版已加入未知 ELF Build ID 地址自动解析与指纹缓存、进程内核心重载地址缓存及分阶段内存映射复用；补齐中文搜索、人物与页面字段、公告、交易、冒险界面和可选 DFHack／Stonesense 原生接入，移除重复搜索绑定。

Windows 工坊安装：从 DFCN/ 将 dfhooks.dll、dfhooks_dfcn.ini 复制至含 Dwarf Fortress.exe 的游戏根目录；INI 第一行指向工坊 DFCN/dfcn/dfhooks_dfcn.dll，其余运行文件留在工坊目录。
Linux 工坊安装：从 DFCN-Linux/ 将 libdfhooks.so 和完整 dfcn 文件夹一起复制至含 dwarfort 的游戏根目录，保留目录结构；配置位于游戏根目录 dfcn/data/runtime/config.ini。

本次使用现有已构建产物打包。未操作游戏，尚未观察本次安装后的游戏内最终显示与流畅度。
