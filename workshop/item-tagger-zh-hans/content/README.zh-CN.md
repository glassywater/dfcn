# 物品标签汉化数据

对应本机订阅的 Item Tagger（工坊 ID 3745671482，数字版本 10）。翻译模组名称、简介、更新说明、窗口标签、九种用途标签、帮助与脚本消息。命令、RAW ID、配置路径保留原样，便于原命令继续使用。

名称规则接受一至九个已知标签的任意顺序，在完整翻译原材料、植物、果实、种子、肉类、鱼类名称后附回中文标签，另覆盖岩浆安全砖块的前置标签。材料和植物名称共享 DFCN 的原版及其他已加载翻译扩展；不会用任意英文通配符伪装成中文，也不改原脚本对英文标签的识别。

地图悬停提示和地形标题也通过原有地形植物词表组合标签，支持灌木、幼株、树苗、根、树干、树枝、细枝及树冠，并保留枯死、积雪等既有修饰。带标签的植物复用已有 mod 名称译文，例如 `Lonely Mints [edi]` 对应 `怕寂寞薄荷 [可生食]`，无需为每个植物另列组合词条。

本包不修改原模组或世界规则，不执行 Lua，无需在创建世界时启用。需要原模组所需的 DFHack 和支持数据扩展的 DFCN。自定义 DFHack 窗口、终端动态输出及名称显示的最终效果取决于 DFCN 的现有界面识别能力。尚未发布，尚未观察游戏内效果。
